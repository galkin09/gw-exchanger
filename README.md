# gRPC Exchanger

это сервис, который предоставляет API для получения курсов валют и конвертации между ними. 
Сервис использует gRPC для взаимодействия с клиентами и PostgreSQL для хранения данных.
---
## Функции 
- Получение всех курсов валют. (GetExchangeRates)
- Получение курса для конкретной валютной пары. (GetExchangeRateForCurrency)
- Автоматическое применение миграций базы данных при запуске.
- Логирование всех операций
---
## **Стек**
- **Язык программирования:** Go
- **База данных:** PostgreSQL
- **gRPC:** Для взаимодействия с клиентами
- **Миграции:** golang-migrate
- **Логирование:** slog
- **Контейнеризация:** Docker
---
## **Установка и запуск**

1. Убедись, что у тебя установлены:
    - Go (версия 1.20 или выше)
    - PostgreSQL (версия 14 или выше)
    - Docker (опционально)

2. Клонируй репозиторий:
   ```bash
   git clone https://github.com/galkin09/gw-exchange.git
   cd gw-exchange
3. Установи зависимости:
    ```bash
   go mod download
4.  Измени файл .env, если необходимо на свои вводные
5. Запусти PostgreSQL
6. 

    ```bash 
   go run main.go
